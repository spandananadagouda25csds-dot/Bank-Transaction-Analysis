SpendDNA — Bank Transaction Analysis

Project Overview

SpendDNA is a Python-based bank transaction analysis project that analyzes transaction data to understand spending patterns, transaction categories, and financial activity through data cleaning, exploratory data analysis, and visualizations.

Objectives

* Clean and preprocess bank transaction data.
* Identify and handle missing values and duplicate records.
* Standardize date formats and prepare data for analysis.
* Analyze transaction amounts and spending patterns.
* Create visualizations to communicate insights.
* Present the results through a transaction dashboard.

Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook / Google Colab
* CSV datasets

Project Files

* SpendDNA_Spandana.ipynb — Notebook containing the analysis and Python code.
* Bank_Transaction_Dashboard.png — Transaction dashboard visualization.
* Cleaned_Bank_Transactions.csv — Cleaned transaction dataset.
* Final_Bank_Transactions.csv — Final transaction dataset.
* Final_Project_Results.csv — Project analysis results.

Methodology

1. Load the transaction dataset.
2. Inspect the data structure and data types.
3. Check for missing values and duplicate records.
4. Clean the data and standardize date formats.
5. Perform exploratory data analysis.
6. Generate visualizations and summarize findings.

Expected Outcomes

* A cleaner and more consistent transaction dataset.
* Better understanding of transaction and spending patterns.
* Visual summaries of the analyzed data.
* A reproducible Python-based analysis workflow.

How to Run

1. Download the project notebook.
2. Open it in Google Colab or Jupyter Notebook.
3. Upload the required dataset when prompted.
4. Run the notebook cells in order.
